# HABRO Installer

App experimental para diagnosticar la preparación de una instalación HABRO sobre Home Assistant OS.

Home Assistant continúa montado estrictamente en solo lectura: esta versión no instala, actualiza, elimina ni reinicia componentes. El journal, los backups, el staging verificado y el commit conjunto se prueban únicamente sobre raíces aisladas; todavía no están conectados a la interfaz.
